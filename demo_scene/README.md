# 最小六设备演示工厂

场景链路：

```text
Spawner pt_1 → Conveyor A pt_2 → Inspection B pt_3 → Robot C pt_4 → Conveyor D pt_5 → Despawner pt_6
```

参数（基准）：输送机 4 m / 0.5 m/s；检测节拍 2 s、通过率 0.95；机器人节拍 4 s；
Spawner 15 件/分钟（4 s 间隔）；仿真 600 s、seed 42。

## 文件

| 文件 | 内容 |
|---|---|
| `oip_project.json` | 可直接导入 OIP 的六设备工程（布局真源） |
| `oip_project_animated.json` | 可动画版本：Spawner 置于皮带起点上方、两段皮带首尾相接，OIP 中 ▶ 可见箱子流动（仅视觉演示） |
| `unified_scene.json` | 平台统一场景（设备/端口/显式连接/仿真参数，最终 v8） |
| `baseline_experiment.json` | 基准实验（实际 Python 引擎运行结果，600 s） |
| `optimized_experiment.json` | 应用优化建议后重跑结果 |
| `optimization_record.json` | 规则式优化：候选建议、真实重跑对比、最佳方案 |
| `edge_experiment.json` | EdgeCoder 三种调度策略结果（任务由该场景实验生成） |
| `report.md` / `report.html` | 场景仿真报告 |
| `load_demo.py` | 一键加载并重跑基准/优化（不依赖服务） |
| `demo_meta.json` | 项目/场景/实验 ID 索引 |

## 加载方式

### A. 平台 UI（推荐）

1. `start_platform.bat`（或 `python run_platform.py`）。
2. 进入「建模分析工作台」→ 选择/新建场景 → ① 建模里展开「导入 OIP 工程 JSON」→ 上传 `oip_project.json`（或可动画版）。
3. 在 OIP 编辑器中按 Ctrl+S 或点击「同步到 AIC」，场景即转换为统一设备模型。
4. 回到工作台 ② 采集数据运行离线/实时仿真，③/④ 做分析与优化、生成报告。

> OIP 编辑器顶部 ▶ 运行的是 OIP 自身物理动画，只用于视觉演示；生产 KPI 一律以 Python 离散事件仿真为准。

### B. 命令行（离线加载 + 真跑）

```bash
python demo_scene/load_demo.py --duration 600
```

会创建/复用项目、创建新场景、导入 OIP 工程、写入基准参数，并真实运行基准与优化参数。

| 平均产能 | 420 件/小时 | 582 件/小时（+38.6%） |
| WIP | 9 | 10 |
| 平均生产周期 | 73.0 s | 51.4 s（-29.6%） |

| 瓶颈 | Conveyor A（96.9%） | Conveyor A（93.5%），Robot C 升至 61.7% |

| 策略 | 时延满足率 | 平均时延 ms | 超时 | 拒绝 |
|---|---|---|---|---|

## 可动画版本（`oip_project_animated.json`）

原始工程是“逻辑布局”：设备沿 X 轴等距摆放、Spawner 与皮带同高且不在皮带正上方，OIP 物理运行后箱子会堆在 Spawner 下方。可动画版只调整了**位置**（不改参数与显式连接）：

- Spawner 移到 Conveyor A 起点正上方 `[-6.5, 2.5, 0]`；
- Conveyor A `[-4.5, 2, 0]`（−6.5…−2.5）与 Conveyor D `[-0.5, 2, 0]`（−2.5…1.5）首尾相接；
- Despawner 移到皮带末端 `[1.7, 2, 0]`；
- Inspection/Robot 移到皮带侧上方，避免挡住箱子。

在 OIP 编辑器点 ▶ 后，箱子从起点沿两段皮带连续移动，到末端被移走。Python 仿真的显式连接仍为 `pt_1→pt_2→pt_3→pt_4→pt_5→pt_6`，基准 KPI 不变（70 良品 / 420 件每小时）。

已保存示例项目：`PRJ-20261030-DDC29B`（OIP 开源示例产线）包含两个场景：
`SCN-20261030-232953-8736`（最小六设备产线，静态布局）与 `SCN-20261030-234230-6C86`（六设备产线·可动画演示）。
