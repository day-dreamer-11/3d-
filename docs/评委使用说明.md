# AI 数字工厂 · 评委使用说明

## 一、安装（无需任何开发环境）

1. 双击安装包 `AIIndustrialFactory-Setup-1.1.1.exe`；
2. 按向导完成安装（默认安装到当前用户目录，不要求管理员权限）；
3. 安装完成页保留「在默认浏览器打开 AI 数字工厂」，点击「完成」；桌面快捷方式为可选项。

> 安装包已内置 Python 运行时、全部依赖、OIP 三维编辑器与 Python 仿真引擎。
> 评委电脑**不需要安装 Python、Node.js、Docker 或任何开发工具**，安装后即可离线使用。

## 二、启动

1. 安装后可直接进入默认浏览器；以后从开始菜单打开 **AI 数字工厂**；
2. 启动器会自动选择空闲端口、启动工作台与本地服务、执行健康检查；
3. 约 5–15 秒后，默认浏览器自动打开：

```text
http://127.0.0.1:<自动选择的端口>
```

4. 首次启动默认选中 **视频演示案例 · 输送与质检产线**，与参赛实机录屏的场景、参数和已完成实验一致：
   - 进入 **场景编辑器** 查看输送线、检测工位、机器人及装饰模型；
   - 进入 **建模分析工作台**，无需先运行，即可查看已保存的仿真结果；
   - 在 **实验历史** 查看优化前后对照（10 分钟、种子 42，良品 70 → 97 件，产能 420 → 582 件/小时），以及任务调度结果；
   - 点击 **一键演示** 按 10 分钟、种子 42 重新仿真；可修改参数继续操作，在场景编辑器中「另存为」保留自己的方案。

5. 同时保留原有两个演示项目，可通过侧栏「当前项目」切换：
   - **自建工厂演示项目**：六设备产线 + 6 个装饰模型 + 基准/优化实验与报告；
   - **OIP 开源示例产线**：静态场景与「可动画演示」场景。

场景 API 与 OIP 编辑器由平台按需自动启动，无需手动操作端口。

如果浏览器没有自动打开：再次双击快捷方式，会打开已在运行的平台；
仍失败请从开始菜单运行 **「AI 数字工厂（诊断控制台）」** 查看错误信息。

## 三、界面与演示

主导航五页：

| 页面 | 用途 |
|---|---|
| 平台总览 | 项目与最新实验指标 |
| 场景编辑器 | 内嵌 OIP 三维编辑器；打开后自动运行动画，可暂停/停止 |
| 建模分析工作台 | 场景与设备 → 仿真采集 → 数据分析 → 优化归档 |
| 实验历史 | 历史实验与同场景对比 |
| 系统设置 | 服务状态、路径与边界说明 |

快速演示：

- 点击侧栏 **「▶ 一键演示」**：自动选择演示场景、运行离线仿真并跳转到分析结果；
- 在工作台 ② 启动 **实时仿真** 后切到「场景编辑器」，右侧会出现「实时仿真联动」面板，显示仿真时间、良品与逐设备状态，并自动高亮阻塞/故障设备；
- 「场景编辑器 → 部件 → 装饰」分类中是可摆放的三维装饰模型（工具车、人字梯等），仅用于观感，不参与生产仿真。

## 四、停止

任选一种：

- 开始菜单 → **停止 AI 数字工厂**；
- 关闭浏览器**不会**停止后台服务（服务继续占用本机端口，方便下次秒开）。

## 五、数据与升级

- 项目、实验与运行状态保存在：

```text
%LOCALAPPDATA%\AIIndustrialFactory\
```

- 重新安装/升级不会删除该目录；卸载默认**保留**用户数据；
- 如需彻底清理，停止服务后手动删除上述目录；
- 日志位于 `%LOCALAPPDATA%\AIIndustrialFactory\logs\`。

## 六、系统要求

- Windows 10/11 64 位；
- 4 GB 内存以上（推荐 8 GB）；
- 约 1.2 GB 可用磁盘空间；
- 浏览器：Edge / Chrome 均可（系统默认浏览器会自动打开）。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击后没有浏览器窗口 | 查看 `logs\launcher.log`；再用「诊断控制台」启动 |
| 提示端口被占用 | 重启启动器会自动选择新端口 |
| 三维页面空白 | 等待 10 秒；Ctrl+F5 强刷；确认安全软件未拦截 127.0.0.1 |
| 动画不动 | 在「场景编辑器」选择「六设备产线（可动画演示）」，或点顶部「开始仿真」 |
| 页面显示旧数据 | 数据在 `%LOCALAPPDATA%\AIIndustrialFactory`，可在「实验历史」查看 |

## 八、数据与仿真边界

平台中的产量、OEE、瓶颈与设备状态均由内置离散事件引擎真实计算；
边缘网络时延、任务映射与成本为**仿真参数**，不是真实工厂或 6G 实测数据。
