# 使用说明

## 安装与启动

推荐首次使用者打开 [Releases](https://github.com/day-dreamer-11/3d-/releases)，下载 `AIIndustrialFactory-Setup-1.1.1.exe`。该文件是安装程序，不是安装后的启动快捷方式。

1. 双击安装程序，按向导完成安装。
2. 完成页保留“在默认浏览器打开 AI 数字工厂”，点击“完成”。
3. 首次启动需要一些时间，请等待服务就绪和浏览器自动打开，不要连续重复点击。耗时取决于电脑性能。
4. 以后从 Windows 开始菜单打开“AI 数字工厂”。桌面快捷方式是安装时的可选项。

平台运行在本机，网址为 `http://127.0.0.1:<自动选择的端口>`。安装版包含运行环境和演示案例，核心功能可离线使用；无需安装 Python 或 Node.js。推荐 Windows 10/11 64 位、8 GB 内存和至少 1.2 GB 可用空间，使用 Edge 或 Chrome。

## 第一次体验：先运行现成案例

首次启动会载入“视频演示案例 · 输送与质检产线”。已有项目会保留。

1. 在“平台总览”查看当前项目和最近一次实验结果。
2. 打开“场景编辑器”，查看输送线、检测工位、机器人和物料出口。中文部件库支持检索与摆放设备。
3. 点击侧栏“一键演示”，按演示配置运行 600 秒、随机种子 42 的生产仿真。
4. 在“建模分析工作台”查看良品、在制品、产能和设备状态。结合队列和上下游关系判断哪里等待或积压。
5. 进入质检任务分配区域，比较本地、云端与动态分配策略。比较时同时查看按时完成、超时和拒绝任务，不能只看平均时延。

三维画面用于展示场景和联动状态，生产指标由 Python 场景引擎计算。装饰物不参与生产能力计算。

## 修改、保存与对比

- “保存”更新当前场景；“另存为”保留独立副本，适合尝试新方案。
- 修改输送速度等参数后重新仿真，查看产量和设备效率是否一起改善。
- 公平比较时，应保持场景、仿真时长和随机种子等条件一致，只改变要研究的参数。
- 在“实验历史”选择同一场景的两次记录，查看结果差异，并回查参数。
- 在报告区域导出 JSON、Markdown 或 HTML，便于复盘和分享。

## 数据、退出与排查

安装版数据及日志位于 `%LOCALAPPDATA%\AIIndustrialFactory`，日志子目录为 `logs`。升级与卸载默认保留用户数据。源码入口 `run_platform.py` 的项目数据通常位于项目下 `data/`，不要将个人运行数据提交到 GitHub。

关闭浏览器不会停止安装版的后台服务。需要退出时，使用开始菜单中的“停止 AI 数字工厂”。

| 问题 | 处理方法 |
| --- | --- |
| 浏览器暂未出现 | 等待启动完成；仍失败时打开“AI 数字工厂（诊断控制台）”，查看日志 |
| 三维页面空白 | 等待资源加载，刷新页面，确认本机服务没有被安全软件拦截 |
| 源码版缺少编辑器 | 按 README 构建 OIP 和 RFTwin 前端，然后重新启动 |
| 修改后结果没变化 | 确认保存到了当前场景，并重新运行实验；不要只查看旧记录 |
| 端口已被占用 | 启动器通常自动换端口；按控制台或日志中显示的地址访问 |

当前版本用于软件仿真与方案预演，不是实际工业控制系统，也未接入 6G 实网。现场部署前需要用真实设备、网络和模型数据校准验证。
